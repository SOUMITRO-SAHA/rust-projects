# Learning Rocket (Rust Backend Framework) by building Todo APIs

#### APIs

- Get All Todos at ('/')
- Get A Sepcific Todo or Get Todo by ID ('/:id')
- Create a new Todo('/') | POST
- Create Multiple Todos at once | POST
- Update a Todo ('/:id') | PATCH
- Delete Todo ('/:id') | DELETE
- Delete All Todo ('/') | DELETE

#### Topics

- Redirect
- Send Json Response
- Send Status Code
- Database Connection | Database Configuration
